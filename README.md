# MG TECHNOLOGIES website

A responsive, static company website designed to deploy free on Vercel.

## Files
- `index.html` — page content
- `styles.css` — responsive corporate styling
- `script.js` — mobile navigation and footer year
- `assets/logo.svg` — original MG Technologies vector logo

## Before publishing
1. Replace `hello@mgtechnologies.co.za` in `index.html` with a contact email that you and your parent/guardian are comfortable publishing.
2. Check all wording and service offerings with your parent/guardian.
3. The work cards are clearly labelled concept demonstrations; replace them with genuine work as your portfolio grows.
4. Do not publish your home address, personal phone number, school details or private information.

## Deploy using GitHub + Vercel (phone-friendly)
1. Extract this ZIP on your phone.
2. Create a new GitHub repository named `mg-technologies-website`.
3. Upload the files and folders inside this project. `index.html` must be in the repository root.
4. Sign in to Vercel using GitHub and choose **Add New → Project**.
5. Import `mg-technologies-website`.
6. Framework preset: **Other**. Build command: leave blank. Output directory: leave blank. Install command: leave blank.
7. Select **Deploy**. Vercel will provide a free `*.vercel.app` address.

No database, paid service or environment variables are required for this first version.
